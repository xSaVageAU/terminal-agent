# Terminal Agent

Terminal Agent is a concise CLI assistant that helps you manage tasks, explore your codebase, and interact with your terminal environment using LLMs.

## Features
- Interactive CLI interface
- LLM-powered assistance
- Integrated tools for system and workspace operations

## How to Build

Ensure you have [Go](https://go.dev/) installed.

```bash
go build -o terminal-agent main.go
```
